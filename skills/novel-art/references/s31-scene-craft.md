# 场景设计补强（源自老唐场景 skill 3.1 要点，内化改写）

## 一、设计前先答场景身份五问

动手写场景设定之前先答五问，答案记进该场景的设计说明，原文有答案用原文，没有的按最自然的推定并标明是设计、不是剧情事实；推定不得与原文矛盾，不得改变布局、出入口、物件数量与剧情：
1. 谁在这里：使用者的身份、职业、人数、性格倾向。
2. 用来做什么：主要功能、次要功能、日常动线。
3. 什么年代、地域与技术水平：决定建筑构造、家具形制、材料与工艺（与 dynasty 口径一致，不另起一套）。
4. 用了多久、维护得怎样：崭新、常用、老旧、失修、废弃，决定痕迹的多少与位置。
5. 此刻处于什么状态：营业中、刚收工、深夜无人、刚经历冲突、节庆布置等。

## 二、三级细节与密度梯度

场景细节分三级写，不许只堆名词：
- 一级·结构骨架：梁柱、墙体构造（砌法、木构、夯土）、门窗形制与框料、地面铺装、天花构造、层高与高差——写构造方式，不只写「墙」「地面」。
- 二级·功能陈设：按功能区配置的家具、设备、器具，每件写形制、材料、朝向与相互关系。
- 三级·表面与生活痕迹：小件杂物、工艺细节、使用磨损、环境沉积，写具体位置与状态。
密度分梯度：视觉中心与功能核心区最密；通路、地面中央、大面墙体留呼吸区；画面边缘与远景降一档，只留轮廓与色块。不平均撒满——细节越多越要分主次，否则只是一堆杂物。同类小件成组出现（一排瓶罐、一摞书），比零散单件更容易被模型画准。每张图至少留一两件人人熟悉的尺度物（门扇、台阶、椅子、书本、碗筷），无人空景尤其需要。

## 三、材质词锁定与磨损使用逻辑

- 材质写三件事：基材（具体到种类：老榆木、水磨石、青砖、夯土、粗陶、铸铁，不只写「木头」「金属」）、工艺（榫卯、铆接、焊缝、手工抹灰、釉色窑变）、状态（新旧、干湿、磨损位置、氧化、包浆、褪色、开裂、污渍分层）。
- 材质词锁定：首图（母场景设定板）定下的材质名词，在全部变体与后续引用中原样复用——母版写「包浆老榆木柜台」，变体不许写成「深色实木柜台」。换说法就是漂移源。
- 磨损只长在有使用逻辑的位置：手常碰（门把手、桌沿、柜台前沿、椅背顶）、脚常踩（门槛、台阶中央）、水常流（墙脚、灶台上方、窗台下缘）处才写痕迹；新建或精心维护的空间痕迹少而轻，废弃空间以积尘、剥落、锈蚀为主。痕迹不改变结构完整性，不暗示原文没有的事件（与 scene-pass 表面处理 A／B 两档口径一致，选档仍按原规则）。

## 四、色彩配方

每个场景定一份色彩配方，写进设计说明，全场（含全部变体）一致：
- 主色取自场景大面积材料与主光，辅色来自次级光或第二大材料，点缀色只用在少数小面积物件上，用得少才有分量。
- 饱和度与明暗基调（明亮低反差／低调高反差等）全场统一；跨变体不改白平衡基准，否则看起来像换了时间。
- 色调统一不能把白墙染成另一种材质，也不能抹掉家具识别色与关键结构色。

## 五、锚点反拍（可选路线，正反打重的场景才用）

默认不做。某场景正反打镜头多、反打关键帧靠现有设定板脑补反面风险大时，可为该场景补一张反向视角板：
1. 先有已确认的母场景设定板（首图），没有首图不写反拍词；首图与文字设定冲突时先定采用哪套，不静默选边。
2. 从首图选锚点：近处锚点 P（靠近原观察者的一件可辨物件或结构）、远处锚点 Q（另一端的一件）、必要时侧向锚点 R（不对称元素，防镜像）。
3. 反拍提示词正文逐条写清每个锚点在新机位下的结果：位于相机前方／身后／侧方、新画面里是前景／中景／远景／被遮挡／画外、可见面是正面／背面／侧面／顶面。不许只写「换到对面看」，不许机械互换近远——相机越过 Q 后 Q 可能在身后完全不入画。
4. 共轴一句话原则：正反两机位尽量共用一条拍摄轴线、相同视高与画幅，只换端点不横移居中；世界里的物件、光源、材质词全部不动，只重算透视、遮挡、可见面与受光。
5. 反拍板沿用母场景的画风口径、光照状态与表面处理档；生成后逐锚点验收（身份、位置、可见面、光源方向），不合格改站位句与映射句，不靠加重「严格参考」反复抽卡。
6. 登记方式：反拍板文件命名 `SC_xx-REV.png`，在该集美术报告里登记一行（art.json 的 schema 没有挂补充设定板的字段，不为此改 schema）。
