# 编剧工艺补充 · 密度、信息差、反转与伏笔

> 来源：学习自 Toonflow-app（MIT License）`packages/skills/v118workflow/references/knowledge/scriptCraft.md`，已剥离其画布与工具绑定、按本仓库口径内化改写，不是原文复制。

`script-pass.md` 管一集怎么写得能演、能生成。这份文件补的是它没有系统展开的四件事：事件的三种密度判断、信息差的登记方法、反转与伏笔的登记方法、把心理与设定写成画面的方法。写戏之前先读对应小节，写完之后用文末清单自查。

## 事件与三种密度

先区分事件与情节：事件是发生了什么，情节还要说明为什么发生、怎样改变冲突、给人物造成什么不可逆的变化。每一场戏写之前先回答三个问题：

- 情绪密度：观众此刻感受什么，由什么可见行为触发，前后强度有没有变化。一直同一种强度等于没有强度。
- 信息密度：这一场新交代了什么，为什么必须现在交代，知情者是谁，释放位置在哪一拍。
- 情节密度：上一场的结果怎样成为这一场的原因，冲突升级、反转还是处境改变，三者至少占一样。

与主线的关系分三档：强是直接推动主角目标或人物弧，中是补充关系、规则或必要伏笔，弱是过渡与气氛。弱不等于删除，温情题材的日常与悬疑题材的延迟揭示都有叙事功能，结合题材判断去留，不按统一的快节奏模板砍。

## 矛盾升级的四级阶梯

矛盾是持续存在的欲望与阻碍，冲突是人物为解决矛盾采取的行动。检查一场戏的冲突有没有真的升级，看它落在哪一级：

1. 欲望与阻碍成立：主角想得到某样东西，另一方控制着它。
2. 强化：欲望变紧迫、阻碍变有力，形成不能两全的选择。
3. 深化：双方的欲望都有可理解的理由，选择变难，而不是把对手写成纯粹的工具人。
4. 升级：主角的行动引出更严重、不能轻易撤回的后果，新冲突来自前因。

只增加吵架与打斗的音量不算升级。人物弧同样要有行动证据：初始信念 → 触发事件 → 用旧方式行动 → 代价迫使反思 → 新选择 → 最终状态，不能只在结尾宣告人物成长了。

## 信息差登记

每一个关键段落填写一张信息差表，写戏时随身带着：

```text
真实事实｜主角知道什么｜对手知道什么｜观众知道或误以为什么｜本段揭示什么｜下段还欠什么
```

四种知情关系各有各的用法：

- 主角与观众知道、对手不知道：观众等待行动兑现，看对手误判及其后果。
- 对手与观众知道、主角不知道：观众替主角担忧，看他一步步接近陷阱。
- 观众知道、双方角色都不知道：观众等待相认或关系解开，同一事实分散在双方行动中，观众先连起来。
- 观众跟随一方只知局部：共同调查、共同受骗，每一次增加一条可核对的线索，不凭空补答案。

钩子解决一个阶段问题之后再提出主线新问题，不使用永不兑现的方式吊胃口。

## 反转与伏笔登记

全局反转三种方法：

1. 预期误导：展示真实线索，用常见理解建立错误结论，再由另一条真实细节推翻。回看的时候原先的画面仍然成立。
2. 人设重释：先建立角色标签，埋入不完全符合标签的行为，最后揭示另一面。改变主角已经确认的核心价值，必须先取得用户同意。
3. 动机置换：同一个行为同时符合表层动机与深层动机，双轨都给出证据，揭示深层动机之后旧行动获得新解释。

单集反转三种方法：常用道具的真实功能被重新理解；情绪预期落空之后由人物行动完成回弹；真实局部画面产生误判，再用全貌揭示。同一种招不连续重复使用，反转不许改变已经展示过的客观事实。

重大反转先登记再写剧本，使用这张伏笔登记表：

```text
反转或兑现点｜来源事实｜观众的初始理解｜预埋的集与场及细节｜揭晓的集与场｜揭晓后如何解释旧细节
```

## 把心理与设定写成画面

- 情绪有四条表现通道，优先顺序是：行动（握紧又松开的手）、语言（改口、停顿、节奏变化）、环境（声音或空间改变）、必要的独白。前三条能交代的，不写心理解释。
- 画面化五法：写场景只写与剧情有关的光线和空间，不写家具清单；写细节不用形容词代替行为（不写「她很坚强」，写「听见孩子哭，抹掉眼泪挤出笑」）；动作触发台词、台词改变下一步行动，不站桩交代设定；关键位置（开场、兑现、情绪转折、真相揭示）写清观众必须看见什么；必要的视听手法（逆光轮廓、声音先到）使用可实现的画面语言表达，不把制作参数夹进剧本正文。
- 世界观分段释放：每一集只回答这一段需要的那条规则，用行动后果让观众看出来，写清由谁引出、解释到暗示还是明确、观众跟随谁、下一次补充落在哪一集。
- 重要沉默写清三件事：是谁不说、为什么不说、可见反应是什么。沉默在博弈场合是施压手段，要标明施压的一方与承受的一方。
- 人物出场入口有七种可选：局部细节、关键动作、配角反应、先闻声音、环境反差、标志道具、氛围铺垫。选择最能暴露人物欲望与性格的一种，写成具体的登场动作，不写空泛的隆重登场。

## 写完之后的自查清单

- 每一场戏的三种密度各有一条能写下来的答案，情节密度与上一场有因果承接。
- 冲突落点在四级阶梯的哪一级，与上一场相比是升级、深化还是原地重复。
- 信息差表填写完整，观众这一段新知道什么、还欠什么都说得清。
- 本集认领的反转在伏笔登记表里有预埋记录，揭晓方式能解释旧细节，没有改动已经展示过的客观事实。
- 心理活动已经转成行动、语言或环境变化，直接写心理解释的句子逐条复查。
- 台词逐句检查功能：推动行动、塑造人物、形成信息差、改变情绪，四者至少占一样，只重复问答与自报身份的句子删除。
