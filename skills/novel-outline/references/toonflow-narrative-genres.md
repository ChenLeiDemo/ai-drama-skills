# 叙事类型方法 · 选型与节拍骨架

> 来源：学习自 Toonflow-app（MIT License）`packages/skills/v118workflow/references/knowledge/narrativeGenres.md`，已剥离其画布与工具绑定、按本仓库口径内化改写，不是原文复制。

大纲阶段的题材不能只落在 `params.genre` 一个标签上。选定主类型之后，这一集的节拍往哪里走、信息怎么释放、结尾给观众留下什么感受，都由类型方法决定。这份文件给出选型方法和十二类叙事的节拍骨架，写骨架与分集梗概时按主类型读取对应小节，融合类型再读辅助类型的小节。

## 选型方法

- 先从原著的实际内容判断主类型，不按市场热度硬套。判断依据是故事核的矛盾形态：关系拉扯是言情，证据与误导是悬疑，代价与抉择是末世或史诗。
- 只定一个主类型，可以再定一个辅助类型。辅助类型只提供局部方法（例如主类型悬疑、辅助类型家庭提供情感锚点），不另起一条节拍线。
- 把选型结论写进改编说明：主类型、辅助类型、观众看完每一集应当留下的主要感受、本类型明确不使用的手法（例如温情题材不使用强反转骗局、悬疑题材不使用无依据的新增事实反转）。
- 类型是方法选择，不是题材禁令。类型之间可以融合，但每一集只能有一条主节拍线，融合先体现在单场手法上，不体现在结构上双轨并行。
- 下列节拍骨架是结构参考，不是平台规则。集数、单集时长与原著体量不同的时候，按比例迁移，不机械凑满每一个环节。

## 十二类节拍骨架

### 甜宠言情

初见发现 → 暗恋克制 → 靠近又退缩 → 误会或分离 → 行动解开心结 → 更深的靠近或承诺。每一轮推拉必须改变双方的理解或关系状态，恢复原状再重复一轮就是原地踏步。情感增量优先用可见行动承载（物件传递、距离变化、替对方做的事），少用旁白宣告。

### 悬疑推理

正常表面出现裂缝 → 发现异常 → 调查 → 看似成立的解释 → 新证据推翻 → 回溯拼图。真相分三到五层释放，每释放一条有价值的信息就留下一个新的具体疑问。重要证据至少出现两次：先自然出现，后揭示意义。反转只能重新解释已经展示过的事实，不许靠结尾临时添加新事实。

### 热血少年与动作

先建立为什么而战 → 危机检验信念 → 真正失败并付出代价 → 蓄力 → 临界爆发 → 代价或喘息。成长要用行动变化来证明（从躲闪到迎击、从倒下到再次站起来），不靠角色自己宣告变强。每一轮对抗先写清双方目标、能力差距与限制，翻盘才有可追溯的准备。

### 喜剧搞笑

建立正常逻辑 → 小意外 → 补救让事情更糟 → 误会连锁 → 失控 → 真情或回归 → 最后一记余味包袱。包袱使用三遍法则：第一次建立模式，第二次强化，第三次必须改变。误会链要写清谁误解了什么、谁如何误解对方的反应、第三人知道多少，荒诞也要有内部因果。

### 科幻末世

生存危机 → 寻找资源或庇护 → 信任试探 → 短暂微光 → 更大代价 → 道德选择 → 带伤继续。每一次行动都有资源成本，信任从试探、合作走向更高赌注的背叛或坚守。环境衰败程度要与末日时间一致，设定信息优先用文明残物交代，不让角色长篇演讲世界观。

### 都市职场

占优 → 对手借事件反击 → 被动 → 寻找突破 → 小胜或小败 → 新代价。用利益链推动行为：升职、保位、预算、专业信誉、安全感。关键转折落实到具体事件（邮件、泄密、资源决定），中间要有阶段结果，结尾保留关系或原则上的代价，不写无成本逆袭。

### 古风仙侠

预言或旧因 → 修行与羁绊 → 心劫 → 身劫 → 终极选择 → 新领悟。天道与责任、个人情感之间的冲突是主矛盾。每一次领悟必须改变行动并付出代价，不只提升战力。预言、天象、信物、旧记忆分次出现，让观众等待它们如何兑现。

### 历史史诗

宏观局势与微观人物交织，按积蓄 → 爆发 → 沉淀的大波浪推进。群像各自有情感弧，在关键历史节点交汇。时代信息靠命令的后果、秩序的变化、平民生活与人物取舍来交代，不靠长篇旁白重述背景。每个人物规划一个带有不可逆意味的仪式时刻（最后一次回望、举杯、并肩）。

### 家庭温情

日常循环 → 笨拙关心 → 代际分歧 → 分离威胁 → 行动和解 → 回归或传承。日常之下埋一条暗线（逐渐老去、即将离家、关系疏远）。高潮可以只是一顿重新同桌的饭，不必争吵爆发。关心用习惯动作交代（备伞、添饭、留灯、往行李里塞食物），重复出现的日常要写出这一次与上一次的差异。

### 青春成长

以为懂了 → 被事实打破 → 作出新选择。围绕第一次心动、失败、告别或挺身而出的笨拙展开。每一个关键变化绑定一个具体的「那一天」（天气、活动、物件），甜蜜与遗憾共用「时间不能重来」的底色。成长可以是沉默与行动，不写成功利胜负，不用一场说教代替经历。

### 恐怖灵异

正常安全 → 微妙异常 → 异常侵蚀 → 假性安全 → 最坏预感确认 → 日常中残留异常。威胁从远处、外面逐步进入熟悉空间。怪物全貌与威胁来源延迟、分次揭示，观众了解得越多反而越怕。异常优先使用熟悉空间里多出的细节（多一把椅子、照片里多出的人影），结局必须能解释先前异常。

### 心理博弈

表面和平 → 试探 → 裂缝 → 察觉 → 反将一军 → 更深伪装 → 揭底。每一回合先做三方信息表：一方知道什么、假装不知道什么，另一方知道什么、假装不知道什么，观众知道什么。每一句关键对白标注表面意思与真实目的。反转之前用多个独立细节预埋，不靠最后突然出现的证据证明某人早已全知。

## 类型复核清单

写完骨架与分集梗概之后，按主类型逐项自查：

- 每一集的节拍推进是否符合主类型的骨架顺序，有没有把辅助类型的结构整段搬进来造成双轨。
- 信息释放节奏是否符合类型要求：悬疑有没有提前泄底，言情的推拉有没有产生关系增量，末世的行动有没有付出资源成本。
- 人物关系或知识状态在每一集末尾发生了什么变化，能不能一句话说清。说不清的集就是节拍空转。
- 结尾留给观众的感受是否与改编说明里定的离场感受一致。
- 有没有违反本类型的禁忌：悬疑靠新增事实反转、温情强行制造骗局、热血无代价获胜、喜剧铺垫没有建立就抖包袱。
