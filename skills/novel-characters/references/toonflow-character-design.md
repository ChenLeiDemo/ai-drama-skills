# 角色设计补充 · 辨识维度与造型分层

> 来源：学习自 Toonflow-app（MIT License）`packages/skills/v118workflow/references/knowledge/assetDesign.md` 的角色部分，已剥离其画布与工具绑定、按本仓库口径内化改写，不是原文复制。

`profile-pass.md` 已经定了识别锚点与同批区分的纪律。这份文件补两张可操作的表：把「长相要有差异」拆成可以逐项作出选择的辨识维度，以及把「换装」拆成有保持边界的造型分层。写角色卡的时候配合使用，重点解决同批角色共享同一张模板脸、变体换装换成另一个人这两类问题。

## 辨识维度表

用身份、年龄阶段、生活环境、性格与剧情职能推导外观，不使用「美丽」「英俊」「高质量」代替设计。每个角色至少在下面维度里作出两到三项跨角度可辨的选择：

| 维度 | 可以观察的选择 |
| --- | --- |
| 头脸轮廓 | 长、圆、方，颧骨与下颌的关系，额头宽度，下巴形状，不只更换名字 |
| 五官结构 | 眉形、眼裂与眼距、鼻梁转折、唇形、耳廓，写组合而不是堆砌「精致」 |
| 肤发特征 | 由设定确定的肤色、发际线、发色、长度、分缝、卷直程度，胡须、小痣或疤痕 |
| 体态 | 身高关系、体型、肩颈、重心与自然站姿，儿童与老人服从实际年龄 |
| 基础服装 | 与时代、身份、职业及日常状态匹配的完整衣服和鞋，便于后续换装 |
| 气质呈现 | 从视线、眉眼放松程度、嘴角与站姿体现，基础设定图以中性微表情为主 |

清冷克制、温柔倾听、干练利落、青春直接、市井阅历这类观察方向，分别落实到骨相、眼神、表情与生活痕迹上，不固定绑定某种性别、肤色或身高。保留自然皮肤纹理、碎发与适度不对称，避免所有角色都做成精修广告模特。

## 造型分层与变体边界

角色的造型变体按层拆解，每一层写清设计决定与保持边界：

| 层 | 设计决定 | 保持边界 |
| --- | --- | --- |
| 基础身份 | 已经确认的脸、体型、肤发识别点与基准站姿 | 换装不能变成另一个人，明确的变身需求另外记录允许改变的结构 |
| 妆容 | 素肌、日常、场合、盛典或剧情状态，眉眼、面颊、唇部的具体变化 | 妆后仍然认得出角色，道具、天气、动作不自动触发浓妆 |
| 发型与头饰 | 梳理、扎束、盘发、编发与必要发饰 | 发际线、发色与未经授权的长度不变，侧面与背面结构能对应 |
| 内搭 | 贴身层的领口、袖长、面料与颜色 | 层与层之间的关系合理，不穿插、不悬浮 |
| 主服与外套 | 由时代、场合、温度、身份决定的廓形与剪裁 | 正面、侧面、背面是同一件服装，重量与褶皱符合材质 |
| 鞋与配饰 | 完整鞋款、腰带、首饰、眼镜、帽子、包袋 | 不漏鞋，配饰贴合身体，不凭空漂浮或嵌入皮肤 |

使用方法：居家晨起对应素肌与松散发型，通勤对应适度整理与合体衣物，正式会面加强剪裁与局部妆容，婚礼与盛典可以做完整妆造。这些是提案方法，不自动给每个角色添加妆容或饰品。变体以已经确认的基础设定为身份参考，逐项写清不变项与仅改变项，不把所有层同时改一遍。服装设定图不加入手持物品与背景剧情动作，这类内容由独立道具资产与分镜环节处理。
