# 资产提示词：上游版式 + fisher-moss-prompt-expander

资产（角色定妆、场景空景、道具静物）的提示词**不在本技能里手写**。上游给版式，外部技能给措辞。

## 一、三方分工

| 谁 | 给什么 |
| --- | --- |
| `novel-characters` / `novel-art` | **英文短提示词**（`image.prompt` / `image.sheet`）与**设定板版式**（16:9 三区：左 34% 半身像 / 右上三视图 / 右下细节条） |
| [`fisher-moss-prompt-expander`](https://github.com/Work-Fisher/fisher-moss-prompt-expander) | **中文长提示词**：把一句话或一组素材扩成 1500~2500 字的连贯段落，含人物手部、材质光色、构图骨架 |
| 本技能 | **清单与交接**：`assets` 生成每份资产的编号 / 类型 / 设定板路径 / 篇幅档位 / 版式句 / 素材摘要，交给人或 agent 递给 expander |

上游 `image.prompt` **不能直接翻译**——它是标签式的短提示词，翻成中文仍然只有一两百字，缺的正是母稿要的生活痕迹与左右非对称。

## 二、怎么跑

```bash
# 1) 生成资产生图单（每份资产一节：篇幅 + 版式 + 素材 + 待贴位）
node {baseDir}/scripts/comfy-production.mjs assets art.json --cast cast.json --md > 资产生图单.md

# 2) 逐节把「版式 + 素材」交给 expander：
#    使用 $fisher-moss-prompt-expander，按下面的版式扩写这份素材……
#    只输出一个 text 代码块。

# 3) 把输出贴回 assets.<编号>.prompt（production.json 里），导出时才不会被冲掉
```

`assets` 不带 `--md` 出的是 JSON 骨架，供 `seed --assets` 吃。

## 三、三类版式（本技能写死，沿用上游三区比例）

**角色**——三视图设定板是后面 Qwen 垫图的身份锚。只有单张侧脸，锁不住另一张正脸。

```text
16:9 三区：左侧约 34% 半身像（正面平视，中性浅灰渐变底，作为全片面部基准）；
右上全身三视图（正面／左侧 90°／背面，同一身高基准线、等间距）；
右下细节条 3~4 格（面部特写、惯用手与手上道具、服装磨损、鞋）。
细直线分隔，不加边框装饰，不写任何文字标注。
```

**场景**——无人物是硬要求，多一只手整场作废。

```text
16:9：左侧约三分之二主视角全景（机位与后续分镜 image_1 同角度、同焦段）；
右侧三分之一上下两格——上格关键局部特写（门扇五金／地表积水／主光源位置），
下格同一机位的另一光照状态变体。全图无人物、无手，不写任何文字标注。
```

**道具**——纯白底才好抠图。

```text
16:9 纯白底：左为正面正交主视图（约 40% 宽）；中为侧面 90° 与 45° 俯视各一格；
右为细节放大 1~2 格（磨损、刻字或铭牌、锁扣结构）。极淡接触阴影，不写任何文字标注。
```

## 四、篇幅档位

| 档位 | 篇幅 | 谁用 |
| --- | --- | --- |
| `fine` | 1500~2500 字 | 主场景（`primary`）、主角（`importance: protagonist`）、核心叙事道具 |
| `standard` | 350~600 字 | 次要场景、配角、普通道具 |

档位由 `assets` 自动判定，写进生图单的「篇幅」行，直接告诉 expander 要多长。expander 默认就是 1500~2500 字，`standard` 档要显式说「350~600 字」。

## 五、验图清单

生成后按这张单子过一遍，不合格就重抽这一个资产，不要带着坏资产进分镜：

- 三视图 / 细节条都在，没有被合成一格
- 没有 `FRONT` `SIDE` 这类文字标注
- 场景里没有人、没有手
- 近景与远景的材质、旧化程度一致（不是两张拼的）
- 角色同一张脸：左格半身像与右上全身是同一人
- 版式占位与比例大致对（左 34%、右 2/3 之类），大致对就够，不必逐像素

## 六、和后面两步的接口

- `sheet` 路径进 `assets.<编号>.sheet`，分镜卡片的插槽清单印的就是它
- 场景设定板必须与分镜 `image_1` 同机位——这一条没做到，Qwen 合成时整段空间会重画
- 角色设定板是三视图，Qwen 挂图时用同一张，不要一镜换一张视图
