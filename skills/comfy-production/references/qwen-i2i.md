# 分镜关键帧 · Qwen-Image-2.1 多图编辑

一格的图不是凭空画出来的，是把**已经验收的资产**按这一格的构图摆进同一帧。所以提示词的主体是**指令**，不是描摹——把参考图里已有的五官、衣料再写一遍，只会和像素打架，结果就是换脸。

`image_1` 是画布：它决定输出比例、基础光位和空间拓扑。其余按主次排。**画内有什么就必须挂什么**——漏一张，模型当场发明一件，而且通常是最贵的那件（船、马车、门楼）。

## 一、插槽顺位

| 槽 | 挂什么 | 为什么是这个位置 |
| --- | --- | --- |
| `image_1` | 已验收的场景空景 | 画布比例、透视、光位、左右墙面拓扑都由它定 |
| `image_2` | 主要角色定妆图 | 身份、脸型、服装 |
| `image_3` | 次要角色定妆图 | 同上 |
| `image_4..N` | 叙事道具 | 造型与材质，别让模型自己发明 |

ComfyUI 的 `TextEncodeQwenImage21` 按节点实际连线顺序映射 `image_1..N`，提示词里的 `<imageN>` 必须与之一一对应。**剧情关键帧 2~5 张最稳**，超过 5 张开始互相污染（`qwen-coverage` 门会警告）。

挂图按「画面里有什么」，不按「这段属于哪个场」：段在栈桥场，但画面里出现了渡船，就必须把渡船的设定图也挂上。

## 二、单图与多图的写法差别

- **`N = 1`**：不要用 `<image1>` 标签，直接说「图像中」「画面中」。`qwen-slots` 门会拦误用标签。
- **`N ≥ 2`**：每一张都要被 `<image1>`..`<imageN>` 至少指到一次，编号连续，不许出现 `<image4>` 但只挂了 3 张。

## 三、五条硬规矩

1. **显式推进裁边（防空间压扁）**：`image_1` 是深纵深单点透视（长走廊、大厅）而目标要中近景时，必须写「把机位大幅推向……，把 `<image1>` 里近景与中景的标志物（左侧电梯门、垃圾桶、配电柜）完全推出画外」。不写，模型为了塞进所有地标会把 20 米走廊压成 4 米小房间，边缘文字必烂。
2. **不许跨墙克隆**：严格尊重 `image_1` 的左右非对称。素墙一侧就保持素墙，别要求在空白墙那边生成对侧已有的大型设备——那会画出两台双胞胎配电柜。
3. **解剖左右手，优先单手**：面对面交互写「画面左侧人物只用左手扶住右侧人物右肩，右手自然按在身前工具箱上」。四臂交叉必穿模。过肩镜头前景虚化哪侧肩，入镜前臂就写同一侧。
4. **只定格爆发零点**：这张图要喂给 H3 当首帧时，只画动作的**预备态**（脚刚踩滑、门刚撞开一条缝、手刚搭上提手）。把位移和落点画死，视频模型没有可演的了。
5. **正向保留，不写否定**：用「保持 `<image2>` 中人物的面部五官、发型与服装完全一致」，不写「不要改变脸型」。

## 四、正文里不许出现的东西（`qwen-clean` 门逐条拦）

- 画幅比例（`16:9`、`9:16`）——交给 `image_1` 决定
- 像素尺寸（`1344x768`、`768x1344`）
- 文件名（`CH-01.png`）——指代必须用 `<imageN>`
- 权重语法（`(word:1.3)`）
- 否定句（`no blur`、`no extra people`）
- 「图1」「第一张图」「参考图A」这类口语指代

例外只有一个：**末尾那句收尾**。

## 五、固定收尾句（`qwen-tail` 门查）

```text
No text, no watermark, no borders — a single clean full-bleed frame.
```

不写这句，模型会照着上游那些带分隔线的设定板画格子边框。这句里的 `No` 是标准收尾，不算否定句。

## 六、光影融合

定妆图是棚拍光，直接贴进实景会有抠图感。必须补一句：新合成的人物与道具如何受 `image_1` 的主光照射、接触阴影落向哪边、地面有没有倒影、色温怎么统一。

## 七、几条从现场换来的经验

- **一镜一次调用，绝不批量**。批量出图错了整批重来。
- **先出第一段整套**（主帧 + 后续 2~4 格）给人看：画风、资产一致性、正反打构图对了再往后补。一集三四十格，方向错了就是三四十次白跑。
- **拿图先扫三眼**：和场景设定板是不是同一个世界（材质、光、旧化度）；脸和衣服对不对得上角色设定板；有没有多出来的人（背景围观群众是最常见的污染）。
- 单个失败跳过不阻断，最后汇总说明。别为了一张图卡住整集。
- 图不对先怀疑挂图，再怀疑提示词。九成的「凭空多出一个人」是漏挂或多挂了设定板。

## 八、和 FISHER/MOSS 母稿的分工

- **MOSS 母稿**（`moss-t2i.md`）：从零生成资产生设定板，纯文生图，无参考图。阶段二做一次。
- **本文件**：拿已有资产合成每一格分镜，多图编辑。阶段五每格做一次。

两边都出中文提示词，但一个是「描述」，一个是「指令」。把母稿那种长描写贴进 Qwen，等于让模型在两个来源之间选一个——通常选错。
