# 段落接续

分镜表是按段写的，观众是按秒看的。段与段之间如果没人交代交接，观众看到的就是：人物凭空出现、视线对着错的地方、环境声突然换了一个空间。

这三个字段就是为了逼出那三句交代。**它们不是填表作业，是三道让你停下来想一想的门。**

## 一、`enter`：这段从上一段接过来的是什么

一句话，三样东西能写多细写真细：

1. **人物在哪、什么姿态**（上一段落点）
2. **关键道具在哪只手、落在什么位置**
3. **本段新出现的人从哪来**（走廊哪一端、哪扇门、画面哪一侧）

```json
"enter": "承接 SEG-04：小林已滑停在右墙根半跪、右颈出血；陈锋从走廊南端入画，工具箱留在北段地上（画面外）"
```

反例（EP01 实际写法，门会拦）：

```json
"enter": ""                                  // 什么也没交代，于是主角凭空出现
"enter": "陈锋站在走廊中段"                    // 没写从哪来
```

**新出现的人必须点名**，而且名字要跟 `assets.C01.name` 一致——门直接查字符串。

## 二、`exit`：这段把世界留在什么状态

与 `enter` 对称。写完之后回头看一眼下一段的 `enter`，两句话必须能接上：

```json
"exit": "两人同在右墙根，陈锋右膝着地，工具箱不在画内，小林视线从门口转到陈锋脸上"
```

**`exit` 里写下的东西，下一段要么延续，要么交代为什么变了。** 电梯门在这一段结尾合拢锁死，下一段就不能还让主角盯着门缝。

## 三、`sound`：底噪是一条，不是每段一条

```json
"sound": {
  "carry": ["走廊变压器嗡鸣", "湿地滴水"],
  "keep": ["走廊变压器嗡鸣", "远处奔跑脚步"],
  "add": ["膝盖砸地", "粗重喘息"],
  "drop": ["雨声"]
}
```

- `carry`：从上一段继承来的声源。**必须与上段的 `keep` 至少有一个交集**，否则门报「底噪会断档」。
- `keep`：本段结束时仍在响的声源，留给下一段继承。
- `add` / `drop`：本段新增与消失的声源，只记录，不设门。

判据很简单：**把全片各段的 `carry` 首尾连起来，应该是一条不断的线。** EP01 的问题是变压器嗡鸣在 SEG-03/04 有、SEG-05/06/07 消失、SEG-08 又回来——同一个走廊，四段之内换了三次空间。

`add` 里的声源要真的落进 H3 提示词的 `overall_soundscape`；这里只记意图，写不写进去靠人。

## 四、四种合法转场，其余一律不许

段与段的接缝，只能用这四种：

1. **动作接动作**：下一段首帧接着上一段末帧的同一个动作（同一只手、同一方向）。需要抽尾帧 + `dedupeFrames`。
2. **视线接视线**：上一段末镜看某个目标，下一段首镜就是那个目标（或那个人）。`enter` 里写清视线怎么转过去。
3. **声音接画面**：上一段的最后一个声音延续到下一段的画面里（J-Cut），或下一段的声音提前进上一段末尾。
4. **同轴推进**：机位同轴、景别变化（中景推成特写、大全景推成中景），空间不变。

**不许用的**：同一空间不同时间的硬切当顺接；跨空间硬切；用运镜甩过去代替转场（量化版 H3 会崩）；靠字幕/黑场掩盖断裂。

## 五、过桥镜

当两段之间确实缺一个动作，答案不是往 `enter` 里塞一句话，是加一个**过桥镜**：

- 时长 1.5~3 秒（`53f`~`73f`，落在 24fps 格点上取 `56f` / `73f`）
- 必须带来**一个新信息**（谁来了 / 看到什么 / 什么响了），不能只是空镜拖时间
- 只承担一个动作：走进来、抬头、看见、放下东西
- 声音上通常由它承担 `add` 的第一个声源（例如脚步声由远及近）

## 六、顺序：先补拍，再填字段

门报错时有两个选择：补一句 `enter`，或者回去加一拍。

- **状态写漏了**（人物在哪、道具在哪只手）→ 填 `enter` 就行
- **事件根本不存在**（陈锋怎么到的、什么时候发现的）→ 必须回去加拍或加过桥镜

用 `enter` 掩盖缺失的拍，等于把跳跃写成了散文——门过了，画面还是跳。
