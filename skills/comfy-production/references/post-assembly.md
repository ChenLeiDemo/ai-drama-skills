# 成片总装

段跑完不等于片子成立。这一段做四件事：**剪掉尾帧接力留下的重复、把断点藏起来、把底噪接成一条、把响度拉齐**。前三件靠人，第四件与裁剪靠命令。

`post` 命令输出的是表 + 能直接跑的 ffmpeg，不是打包好的成品。它不会替你决定在哪一帧下剪刀。

## 一、裁剪表

| 列 | 含义 |
| --- | --- |
| 帧数 | 该段吸附到 `17k+5` 后的实际生成帧数 |
| 时长 | 帧数 ÷ 24 |
| 头部去重 | `dedupeFrames`：抽尾帧造成的重复，从本段开头裁掉 |
| 有效起点 / 终点 | 裁剪后该段在成片里的入点与出点 |
| 首帧来源 | 直出 / 抽哪一段的末帧 |
| 衔接备注 | `postNote` 与 J-Cut 量 |

**去重帧数怎么定**：抽上一段末帧当首帧时，本段开头 N 帧会和上一段结尾重合。8~16 帧（0.33~0.67s）是常见区间。填大了把本段开头咬掉，填小了留一个可察觉的顿。判据是「动作接上了但看不出重复」——宁可多裁两帧，卡顿比跳帧难受。

## 二、ffmpeg 三步

```bash
# 1) 逐段裁头（-ss 在 -i 前是快速定位，近似到关键帧；要帧精确就放到 -i 之后并重编码）
ffmpeg -y -ss 0.5 -t 3.96 -i E01-02.mp4 -c copy -avoid_negative_ts make_zero clip-E01-02.mp4

# 2) 拼接
printf "%s\n" "file 'clip-E01-01.mp4'" "file 'clip-E01-02.mp4'" > concat.txt
ffmpeg -y -f concat -safe 0 -i concat.txt -c copy joined-E01.mp4

# 3) 响度归一 -14 LUFS
ffmpeg -y -i joined-E01.mp4 -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:v copy master-E01.mp4
```

`-c copy` 的前提是各段编码参数完全一致（同一个工作流出的，通常一致）。不一致会报错或花屏，那就去掉 `-c copy` 重编码一次。

`loudnorm` 单遍模式够用；要更准用两遍：

```bash
ffmpeg -i joined-E01.mp4 -af loudnorm=I=-14:TP=-1.5:LRA=11:print_format=json -f null -
# 抄输出里的 measured_* 四个值，第二遍带 measured_I / measured_TP / measured_LRA / measured_thresh 再跑
```

## 三、人工四步（脚本不碰）

1. **尾帧去重裁剪**：按裁剪表下刀。裁完连看三遍接点，动作轨迹不能有折返。
2. **假甩镜与 J/L-Cut**：段与段之间的硬切换一律不要靠模型甩镜完成。做法是前段末 3 帧加横向动态模糊，本段撞击声提前 2 帧（J-Cut）；情绪转折处让上一句台词的尾音延到下一个反应镜（L-Cut）。
3. **Room Tone 通轨**：全片铺一条环境底噪，各段断点处不静音。这是「像不像一部片子」最廉价也最有效的分界线——没有底噪的接缝，观众一秒就听出来是拼的。
4. **全局轻颗粒统一**：各段如果颗粒/锐度有差异，加一层统一的轻颗粒盖住。不要逐段调，越调越花。

## 四、验收口径

- 响度：整片 **-14 LUFS**，真峰 ≤ -1.5 dBTP。
- 接点：连看三遍，找不到一处「画面顿一下」。
- 声音：任意两段之间没有突然安静的空洞。
- 尾帧链：所有 `tailFrom` 段的开头，动作从上一段的末态继续，没有重演。
- 时长：Σ 裁剪后时长与剧本目标差在 ±10% 内（storyboard 那边已经按 ±15% 校过一次，这里只会更短）。

## 五、归档

```
E01/
├── E01-01.mp4 … E01-0N.mp4      原始段（保留，重剪要用）
├── clip-E01-01.mp4 …            裁剪后（可删）
├── concat.txt
├── joined-E01.mp4               拼接（可删）
└── master-E01.mp4               审片母版
```

原始段永远保留。母版只出一次，改片子回原始段重跑，不要在母版上二次压缩。
