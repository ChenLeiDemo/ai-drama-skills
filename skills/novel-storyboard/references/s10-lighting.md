# 场景光照表（源自老唐 s10 布光要点，内化改写）

每场排镜前先定场景光照表（五项），之后每镜受光从它推出，不逐镜临场发明：

1. 时段与天气（按原稿；没写按剧情最自然的时段，不默认黄昏和逆光）
2. 具名光源（挂在地标上，如“柜台上方的日光灯管”，写颜色倾向与软硬）
3. 主要人物在主视方向下哪一侧受光、暗面朝哪
4. 光比档（柔和／明确／强烈，同场一致；暗面能看清必须写出托住它的东西——白墙、地面、桌面、纸张、雪地、水面反光或另一盏场景里的灯，写不出来源的“补光”不写）
5. 光变节点（有没有、从哪一镜生效；光变必须有看得见的动因——门开、车灯扫过、灯被关等，之后镜头沿用新状态）

对白场先定谁亮谁暗：窗在甲身后时，拍甲是侧逆光、反打乙是顺光更清楚；要读清甲的脸就转机位让窗光变前侧光，或借场景里已有的台灯，不把窗户搬到甲面前。

视觉中心：本镜最亮或反差最强处必须是视觉中心；夜景用光岛（场景里已有的灯、窗、火各照一块），人物走进光岛才看清，暗部保留结构、不一律死黑。

光照表写进该集分镜说明；逐镜只写和它不同的地方。正反打回合交付前按表对账两边受光。
