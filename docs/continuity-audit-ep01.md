# EP01 衔接体检

对象：《风雨欲来》EP01 v3.2 分镜投产稿（13 段 / 12 拍 / 99.8 秒）
目的：定位「分镜之间切换生硬、人物瞬移、视线错位、声音割裂」的根因，判断哪些能变成可机检的门。
结论先说：**根因是节拍粒度，不是切镜技巧。** 12 拍装 99.8 秒，平均 **8.3 秒一拍**，而每拍塞了 4~8 个动作。分镜只能在拍边界上分段，于是每一段都从「这一段该演到哪」开写，没人交代「从上一段接过来的是什么状态」。

## 一、四类断点

### A. 节拍粒度：一拍 = 一段动作段落（根因）

| 节拍 | 原文动作数 | 时长 | 问题 |
| --- | --- | --- | --- |
| 3 | 提箱死盯 / 低语 / 垂目 / 顿箱 / 掏机 / 点亮（6） | 8.00s | 6 个动作 + 15 字台词挤在一段 |
| 6 | 冲入 / 跪稳 / 顿箱 / 扶肩 / 触液眼神骤冷 / 小林揪领 / 嘶喊 / 陈锋看颈（8） | 10.13s | 「陈锋到场」和「发现伤口」被塞进同一拍 |
| 7 | 俯拍咬痕 / 纱布按压 / 拨领口 / 画外发问（4） | 5.17s | 纱布已经按上去了，中间没有取纱布 |

技能里写着「每镜只承担 1 个主导动作」，剧本却按「一段戏」写拍。分镜无法违抗剧本：一拍就是一段，段内切 2~5 秒也只能在既有的 6~8 个动作里分，切不出剧本里没有的「到场」「发现」。

按 2.5 秒一个动作拍折算，99.8 秒应当是 **35~40 拍**，现在只有 12 拍。**缺的那 25 拍，正是观众感到的跳跃。**

### B. 段间没有状态交接（人物瞬移的直接原因）

- 节拍 2 结尾：电梯门「疾速合拢锁闭」
- 节拍 3 开头：陈锋「死盯左侧电梯门缝」

门已经关死了，下一段他还在看门缝。同时全篇没有一句交代陈锋从哪来、什么时候到的走廊中段。

- 节拍 5 结尾：小林「双手撑地惊恐抬头望向左侧」
- 节拍 6 开头：陈锋已经「单膝跪稳…左手稳住小林右肩」

中间缺：陈锋听见喊声 → 从走廊另一头跑来（约 30 米）→ 跪下的完整动线。观众看到的是小林抬头，下一秒两人就贴在一起了。

**症状**：SEG-02 → SEG-03 主角凭空出现；SEG-04 → SEG-05 两人凭空汇合。

### C. 视线与机位不跨段（「看错地方」的原因）

- SEG-04 末镜：小林望向来时的门（北端安全门）
- SEG-05 首镜：双人中景，左陈右林，两人面对面 → 小林的视线只能看向画面右侧的陈锋，**看不到身后的门**

剧本节拍 6 写的是「小林双手猛然死揪陈锋衣领」——但没说他的视线是什么时候、因为什么从门转到人的。这个「看见陈锋」的瞬间没有独立镜头，于是两段之间的因果链断了。

**症状**：SEG-05 小林看正前方镜头，不像在看门，也不像刚被人扶住。

### D. 声音没有共同底噪（割裂的直接原因）

各段 `overall_soundscape` 独立生成，走廊底噪时有时无：

| 段 | 底噪锚点 |
| --- | --- |
| SEG-03 | 配电柜变压器嗡鸣 + 电梯缆绳回声 + 滴水 |
| POST-01 | 变压器嗡鸣（承接） |
| SEG-04 | 钢门撞墙 + 鞋底刮擦 + 身体砸地（**嗡鸣消失**） |
| SEG-05 | 工装摩擦 + 靴底 + 呼吸（**嗡鸣仍无**） |
| SEG-06 | 纱布 + 布料 + 痛呼（**完全没有环境声**） |
| SEG-07 | 牙齿磕碰 + 抓胶带（**仍无环境声**） |
| SEG-08 | 荧光灯电流声（**底噪突然回来**） |

同一个空间，四段之内底噪消失又出现。观众听到的不是「走廊」，是四个不同的录音棚。

**症状**：你说的「背景音极其突兀地转换」。注意这不是音量问题，是**环境声的身份在变**。

## 二、哪些能变成可机检的门

| 断点 | 可机检 | 怎么查 |
| --- | --- | --- |
| A 节拍过载 | 部分 | 一拍内动作分句 > 3 就报警（脚本层，需 novel-script 支持） |
| B 人物瞬移 | **能** | 段级 `enter` 字段必填；本段首镜人物 ∉ 上段末镜人物 时，`enter` 必须写明来源 |
| C 视线错位 | **能** | 段级 `enter` 或首镜 `eyeline` 必须承接上段末镜 `eyeline` 的目标 |
| D 声音割裂 | **能** | 段级 `sound.carry` 必填（本段继承的底噪），与上段 `sound.keep` 至少交集一个声源 |
| A 缺转移拍 | 半能 | 相邻两拍地点或人物集合变化时，中间必须有一拍专门写转移 |

## 三、建议的最小改动

**分镜层（`comfy-production`，不动上游 110KB 脚本）** —— 一次做完，能拦住 B、C、D 三类：

```json
{
  "enter": "承接 SEG-04：小林已滑停在右墙根半跪、右颈出血；陈锋从走廊南端入画，工具箱留在北段地上",
  "exit":  "两人同在右墙根，陈锋右膝着地，工具箱不在画内，小林视线从门口转到陈锋脸上",
  "sound": { "carry": ["走廊变压器嗡鸣", "湿地滴水"], "add": ["急促脚步由远及近", "膝盖砸地"], "drop": ["雨声"] }
}
```

三道新门：`handoff-cast`、`handoff-eyeline`、`handoff-sound`。

**剧本层（`novel-script`）** —— 修根因，改动大，建议单独一轮：
- 一拍一个状态变化：到场 / 发现 / 交代 不许合并
- 一拍内动作分句 ≤ 3
- 相邻拍地点变化时必须存在转移拍

**文档层** —— 四种合法转场（动作接动作、视线接视线、声音接画面、同轴推进）+ 过桥镜规范，写进 references。

## 四、技能解决不了的部分

单段 5~15 秒里，模型能演完的只有一个主导动作。段与段真正的缝合在剪辑台上靠**重叠裁剪**：上段留 6 帧尾巴，下段多给 6 帧头，剪掉那 6 帧。技能能保证素材有重叠、状态写得对，剪不剪得顺取决于时间线。

另外，A 类里「同一事件被切成两段导致动作重复」这一种（节拍 1 的推车已推离、节拍 2 又从跨槛开始），只有让剧本按单向物理阶段拆拍才能根治，属于剧本层的活。
